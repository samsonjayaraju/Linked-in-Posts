From Spec to Pull Request with a Coding Agent

What should happen if someone taps Save twice? Follow a bookmark feature from that design decision to a reviewed change.

Engineer

Define the promise

A reader can save an article once. Saving it again returns the original bookmark ID.

Engineer + coding agent

Plan the data contract

Use the reader ID and article ID as a unique pair. Agree on the response for both a new save and a repeat.

Coding agent

Implement the save and write the tests

Add the uniqueness constraint and save handler. Exercise both paths against the database.

First tap

Create one bookmark and return its ID.

Second tap

Return the same ID. The row count stays at one.

Did both tests pass?If either fails, the agent fixes the handler and reruns both.
Coding agent

Open the pull request

Attach the code change, database migration and results for both acceptance tests.

Human reviewer

Check the edge case before merging
